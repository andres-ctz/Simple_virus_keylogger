# Simple_virus_keylogger

se importa las siguientes librerias
keyboard
time
datetime
utilice un try-exception para tener constancia en consola de que el programa este corriendo bn
iniciamos la grabacion con la funcion recording
y creamos una condicion para terminar la grabacion en este caso cuando coloquemos del teclado la letra Esc el programa finalizara
imprimimos en consola estos pasos para confirmar que si se realiza la grabacion
al mismo tiempo creamos el nombre de nuestro archivos de texto
obteniendo el tiempo actual y la fecha transformandolo con strftime de modo string para el nombre del archivo

siguiente paso del programa abre el archivo de txt el cual sera manipulado ya una vez creado
y registramos lo siguientes evento cuando las teclas se precionen o cuando sean evento como el space o enter se registre como un espacio o salto de linea
y lo demas se registra normalmente
el programa ahi finaliza en consola imprimimos que ya todo de acuerdo al odigo funcion avisara que el archivo se creo y se guardo
 y ya fin
 en el except si algo no funciona registra en conosola el error y finaliza el programa
